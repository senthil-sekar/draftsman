# ADR-0006: API Management with Entra identities

- **Status:** Accepted
- **Date:** 2026-09-16
- **Decision point:** DP-4/DP-5

## Decision
A REST API behind API Management; Entra External ID for policyholders, Entra ID for agents, and managed identities for all Azure resources.

## Budget override
None.
